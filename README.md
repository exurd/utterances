# utterances
utterances repo for exurd.neocities.org

> [!IMPORTANT]  
> When publishing a new article in which warrants a comment section, you will need to allow utterances-bot to create a new issue.
>
> Set utterances up to use `issue-term="og:title"`. On this GitHub repo, Go to `Settings` > `General` > `Features` > `Issues ` > `Issue permissions` and change the creation permissions to temporarily allow all users. Then, create a comment on the article so the bot can create the specified issue for the article. Afterwards, switch the creation permissions back to "Collaborators only" to prevent spam issues. Switch utterances to use `issue-number="[ISSUE_NUMBER]"` to avoid the chance of new issues being created and comments becoming separated by multiple issues.
