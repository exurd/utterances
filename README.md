# utterances
utterances repo for exurd.neocities.org

> [!IMPORTANT]  
> When publishing a new article in which warrants a comment section, you will need to allow utterances-bot to create a new issue. Go to `Settings` > `General` > `Features` > `Issues ` > `Issue permissions` and change the creation permissions to temporarily allow all users. Then, create a comment on the article so the bot can create the specified issue for the article. Afterwards, switch the creation permissions back to "Collaborators only" to prevent spam issues.
